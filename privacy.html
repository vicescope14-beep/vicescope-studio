ViceScope Studio — Privacy Policy

Last updated: 25 November 2026

ViceScope Studio is a personal application used only by the owner of the YouTube channel ViceScope Gaming. It is not a public service.

Data accessed

With the owner's consent through Google OAuth, the application accesses the owner's own YouTube account data: channel, video, playlist and comment data (scope youtube.force-ssl) and YouTube Analytics and Reporting data, including revenue reports (scope yt-analytics-monetary.readonly).

How data is used

Data is used only to manage the owner's channel and analyse its performance. It is not sold, shared with third parties, or used for advertising.

Storage

OAuth tokens and downloaded reports are stored only on the owner's personal computer. No data is stored on external servers by this application.

Google API Services

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. This application uses YouTube API Services; see the YouTube Terms of Service and the Google Privacy Policy.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.
